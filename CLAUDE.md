# Project notes

## UI changes

Before changing the call console (`client/index.html`), read
[client/DESIGN-SYSTEM.md](client/DESIGN-SYSTEM.md) and follow it. If a change adds or
alters a pattern, update that file in the same change.

## Script changes

Read voice-guide.md before you create, edit, or refactor any part of the agent's script, prompts, or response templates. Every line the agent speaks must follow this guide. If a requested change conflicts with the **Non-Negotiables** (Section 2) or **Compliance** (Section 10), don't make it. Flag the conflict to the developer instead. Run the **Pre-Commit Checklist** (Section 13) on every change.
